# 媒体生成用例（tts / tti / media，4.24.0 起内置）

权限：U=任意成员；I=邀请者/管理/群主/白名单/骰主；M=骰主。

前置：语音合成与文生图走「模型」页 api连接 + 模型规则的 `tts` / `image-generation` 用途。
未配置对应模型时，错误路径仍可测（返回可读提示），真实生成路径记 `SKIP(env)`。

| ID | 指令 | 权限 | 预期关键字 | 备注 |
|---|---|---|---|---|
| MED-01 | `.ai tts` | U | `.ai tts` | 无正文 → 回该子命令帮助 |
| MED-02 | `.ai tti` | U | `.ai tti` | 无描述 → 回该子命令帮助 |
| MED-03 | `.ai tts 测试` | U | `已提交语音生成任务 #` 或 `未配置语音模型` | 未配 tts 模型时走错误路径（SKIP(env) 记真实生成） |
| MED-04 | `.ai tti 测试` | U | `已提交生图任务 #` 或 `未配置生图模型` | 同上 |
| MED-05 | `.ai tts 测试 --rate=99` | U | `越界` 或 `参数有误` | 越界在**提交前**拒绝、不建任务（需规则里声明了 rate 的 min/max） |
| MED-06 | `.ai tts 测试 --nope=1` | U | `已提交语音生成任务 #` 或 `未配置语音模型` | 未声明的参数被忽略、不应报错 |
| MED-07 | `.ai tts 测试 --model=不存在的模型` | U | `未找到语音模型` | 模型名不存在 |
| MED-08 | `.ai media` | U | `生成任务` 或 `没有生成任务` | 仅查看，不产生副作用 |
| MED-09 | `.ai media list` | U | `当前页码` 或 `没有生成任务` | 分页视图 |
| MED-10 | `.ai media list --all` | U | `当前页码` 或 `没有生成任务` | `--all` 含全部已结束任务 |
| MED-11 | `.ai media cancel` | U | `.ai media cancel` | 缺任务号 → 回帮助 |
| MED-12 | `.ai media cancel 999` | U | `未找到任务` | 不存在的任务号 |
| MED-13 | `.ai md` | U | `生成任务` 或 `没有生成任务` | 别名命中（`md` → `media`） |
| MED-14 | `.ai media zzz` | U | `.ai media` | 未知子动作 → 回帮助 |

说明：

- **异步语义**：`.ai tts` / `.ai tti` 提交后立即回话（含任务号），生成完成后由**插件直接投递**音频/图片到本会话，不经 AI；不要用「立刻收到语音」作为断言条件，应先断言提交回话，再轮询结果。
- **AI 侧路径**：`generate_audio` / `text_to_image` 也是异步的——AI 提交后拿到任务号，完成后写入会话通知并在会话空闲且未待机时自动唤醒 AI 投递；队列用 `media_tasks` 工具查看/取消。测 AI 路径时不要在提交后立刻期待消息段。
- **旧指令已废弃**：依赖插件自带的 `.tts` / `.tti` 指令随依赖移除而消失，不再测试；`.ai media` 是新入口。
- **参考图**（`--negative` 等 kwargs）只在「模型规则」`[body]` 里声明了对应 `{占位符}` 时才生效，未声明会被忽略——这类用例的预期是「不报错」，不是「参数生效」。
- 生成真实媒体需要：连接里有带 `tts`/`gen` 标签的模型（命名白名单未命中时用 `[types]` 声明）+ 模型规则里有对应 `use` 的 `[body]`/`[request]`/`[response]`。缺任一项记 `SKIP(env)` 并注明缺哪一项。
