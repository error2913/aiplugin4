# 基础控制 + 忽略名单用例

权限：U=任意成员；I=邀请者/管理/群主/白名单/骰主；S=骰主（会话权限≥1 时为邀请者）。

## 基础控制（status/ctxn/on/standby/off/forget/role/model/stop/steer）

| ID | 指令 | 权限 | 预期关键字 | 备注 |
|---|---|---|---|---|
| CTRL-01 | `.ai` | U | `帮助` | 根命令帮助，列出全部子命令 |
| CTRL-02 | `.ai status` | U | `权限`、`计数器模式`、`待机模式` | 快照命令 |
| CTRL-03 | `.ai ctxn status` | U | `自动修改上下文里的名字状态` | |
| CTRL-04 | `.ai ctxn mod 0` | I | `设置成功`、`不自动修改` | 非法值测试后恢复为 0 |
| CTRL-05 | `.ai ctxn mod 1` | I | `设置成功`、`自动修改为昵称` | |
| CTRL-06 | `.ai ctxn mod 2` | I | `设置成功`、`自动修改为群名片` | |
| CTRL-07 | `.ai ctxn mod 9` | I | `帮助` | 非法值错误路径 |
| CTRL-08 | `.ai ctxn set nick` | I | `设置完成` | 异步回复，多轮询 |
| CTRL-09 | `.ai ctxn set card` | I | `设置完成` | 异步回复 |
| CTRL-10 | `.ai on --c=10 --t=60 --p=42` | S | `AI已开启`、`计数器模式:10条`、`计时器模式:60秒`、`概率模式:42%` | |
| CTRL-11 | `.ai on --a=09:00-18:00-5` | S | `AI已开启`、`活跃时间段`、`活跃次数:5` | 注册活跃定时器，结束后清理 |
| CTRL-12 | `.ai on` | S | `帮助` | 无参数错误路径 |
| CTRL-13 | `.ai sb` | I | `AI已开启待机模式` | |
| CTRL-14 | `.ai off --c --t --p --a` | I | `AI已关闭`、`计数器模式`、`计时器模式`、`概率模式`、`活跃时间段` | 按模式关闭 |
| CTRL-15 | `.ai off` | I | `AI已关闭` | 整体关闭 |
| CTRL-16 | `.ai fgt` | I | `上下文已清除` | |
| CTRL-17 | `.ai fgt assistant` | U | `ai上下文已清除` | |
| CTRL-18 | `.ai fgt user` | U | `用户上下文已清除` | |
| CTRL-19 | `.ai role` | I | `当前角色设定名称为` | 记录当前角色名与可用角色列表 |
| CTRL-20 | `.ai role <角色名>` | I | `角色设定已切换到` | 角色名取 CTRL-19 返回的名称；结束后切回原角色 |
| CTRL-21 | `.ai role 不存在的角色名` | I | `角色设定名称错误` | 错误路径 |
| CTRL-22 | `.ai model` | U | `当前模型` | 记录当前模型 |
| CTRL-23 | `.ai model <当前模型名>` | U | `已设置当前会话模型为` | 用 CTRL-22 返回的模型名；为空则 SKIP(env) |
| CTRL-24 | `.ai model clr` | U | `已清除当前会话的模型设置` | 结束后恢复快照模型 |
| CTRL-25 | `.ai model 不存在的模型` | U | `不存在` | 错误路径 |
| CTRL-26 | `.ai stop` | U | `当前没有正在进行的对话` | 无进行中对话时（原 shut 用例） |
| CTRL-27 | `.ai steer` | U | `缺少内容` | 无内容错误路径 |
| CTRL-28 | `.ai steer 测试方向` | U | `当前没有正在进行的对话` | 无进行中对话时 |

## 忽略名单（ignore）

| ID | 指令 | 权限 | 预期关键字 | 备注 |
|---|---|---|---|---|
| IGN-01 | `.ai ign list` | U | `忽略名单为空` 或 `忽略名单如下` | |
| IGN-02 | `.ai ign add @<群成员QQ>` | U | `已添加到忽略名单` | 用群内一个普通成员 |
| IGN-03 | `.ai ign add @<群成员QQ>` | U | `已经在忽略名单中` | 重复添加错误路径 |
| IGN-04 | `.ai ign rm @<群成员QQ>` | U | `已从忽略名单中移除` | 清理 |
| IGN-05 | `.ai ign rm @<群成员QQ>` | U | `不在忽略名单中` | 重复移除错误路径 |
| IGN-06 | `.ai ign add` | U | `参数缺失` | 无 @ 错误路径 |

## 恢复要点

- CTRL-04~09 结束后执行 `.ai ctxn mod <快照值>`（默认 0）。
- CTRL-10~15 结束后按快照恢复触发模式与待机状态（快照为全关则 `.ai off`）。
- CTRL-22~25 结束后用 `.ai model <快照模型>` 或 `clr` 还原。
- IGN 用例自清理。
