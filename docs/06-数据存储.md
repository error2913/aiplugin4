# 06 - 数据存储

插件通过 SealDice 的扩展存储以 JSON 字符串持久化数据，统一经宿主端口 `getHost().storage.get/set`（`src/core/host.ts`），不直接调 `ext.storageGet/Set`。存储是「叠加式」key-value：没有遍历能力，因此需要枚举的数据用分片索引承载（上下文事件/记录页、图片索引、记忆分片、历史归档分片）。

## 存储键清单

### 元信息与配置

| 存储键 | 内容 | 写入方 |
| --- | --- | --- |
| `storage_version` | 存储结构版本号（当前 2） | `src/index.ts` 启动时 |
| `version` | 上次运行的插件版本（启动更新日志） | `checkUpdate` |
| `modelPurposeOverrides` | 全局分用途模型覆盖（use → 模型标识），`.ai model` 与余额不足自动切换写入 | `config/apply/model.ts` |
| `modelContextWindows` | 模型上下文窗口探测缓存（按模型名，跨会话/重启复用） | `model/window_cache.ts` |
| `tokenCalibration` | token 估算校准系数（按模型记录实际/估算比值） | `token_calibration.ts` |
| `blacklist` | 黑名单（用户/群 + 原因） | `block.ts` |

### 智能体与会话

| 存储键 | 内容 | 写入方 |
| --- | --- | --- |
| `agent_<name>` | 智能体配置（默认 `*`、`compress_agent`、`summarize_agent`、`judge_agent`） | `Agent.save` |
| `session_<sid>` | 会话状态：memory、setting（含 `overrides` 会话预算覆盖）、imageManager、stream、bucket、tool、state 等；接入事件账本后**不再保存 `messages`**，旧版回退会话才保留；运行时字段（running/starting/stopVersion/stopEvent/pendingQueue/activeRuns/lastCtx）不落盘 | `Session.save`（关键路径立即写，待机/事件路径 5 秒或 20 条合并一次） |
| `session_<sid>:pending` | 挂起队列轻量分片（仅 content/userId/messageId/kind/systemReason/epId/isPrivate），重载后重建续跑；队列空写空串 | `session/persistence.ts` |
| `session_<sid>:arc:<三位序号>` | **旧版**归档分片（只读兼容）：移出上下文的群聊原文；新版不再写入 | `context/archive_store.ts`（迁移/回退） |
| `session_<sid>:raw:<序号>` | **旧版**窗口移出分片（只读兼容）：超过旧「窗口上限字数」时移出的原文；新版不再写入 | `context/archive_store.ts`（迁移/回退） |
| `group_<gid>` | 群档案：群名、角色、群主、管理员、成员、忽略名单 | `Group.save` |
| `user_<uid>` | 用户档案：用户名 | `User.save` |
| `session_sub:<父会话>:<childId>` | 子代理 child 会话载荷（删除写空串） | 子代理 `SubAgentStore` |
| `subagent_index:<父会话>` | 子代理记录索引（ChildRecord 数组，上限 100） | 子代理 `SubAgentStore` |
| `subagent_seq:<父会话>` | 子代理单调序号（删除不回退，childId 不复用） | 子代理 `SubAgentStore` |
| `subagent:roots` | 产生过子代理的父会话根索引（重载对账） | 子代理 `SubAgentStore` |

### 上下文事件账本

> 当前生产会话使用；只追加、页号连续、只写一次。旧 `messages` 仅迁移/回退时存在，读取后不再写回。

| 存储键 | 内容 | 写入方 |
| --- | --- | --- |
| `ctx_head:<sid>` | 会话头：`nextSeq`/`nextPageNo`/`persistedSeq`/`pageFloor`/`epoch`/`summarizedThrough`/`unsummarizedTokens`/`bytesTotal`/`legacy` | `context/store.ts` |
| `evt:<sid>:<6位页号>` | 事件页（user/assistant/tool_call/tool_result/event），单页 256 条 / 32KB；只写一次，恢复时先采纳页再写 head | `context/log/page_store.ts` |
| `rec:<sid>:<6位页号>` | 记录页（summary/edit/supersede/redact/epoch），只追加 | `context/log/record_store.ts` |
| `mem_cursor:<sid>` | 记忆桥消费进度（consumed/readSeq/offset/pending），重载后不重复沉淀 | `agent/context_bridge.ts` |

### 任务、资源与统计

## 会话 ID 与档案 ID 格式

- 私聊会话：`QQ:<用户ID>`；群聊会话：`QQ-Group:<群号>`；其它平台按 `<平台>:` / `<平台>-Group:` 前缀。
- 群档案 ID 与群会话 ID 相同；用户档案 ID 与私聊会话 ID 相同。
- 工具调用传参前通常 `replace(/^.+:/, '')` 归一为裸 ID；跨平台归一用 `utils/target_id.ts`。

## 序列化与反序列化（revive）

存储内容不是直接 `JSON.parse` 后使用，而是经 `src/utils/revive.ts` 的 `revive()` 恢复：

- 每个可持久化类声明静态 `validKeysMap`，描述字段类型（字符串/数字/布尔/数组/嵌套对象/嵌套类）。
- `revive` 先 `new constructor()` 建默认实例，再按 `validKeysMap` 逐字段恢复，跳过缺失或类型不符的字段，嵌套递归。
- 存档缺字段/增字段可平滑兼容；`Context` 消息与记忆条目在读取后再做二次清洗（`reviveMessages` 等）。

## 保存节流与写穿

- 高频入库路径（待机消息、事件）`Session.save(coalesce=true)`：5 秒或 20 条最多落盘一次，并安排兜底写入；回复、命令、归档等关键路径立即写。
- 记忆巩固全程 `persist=false` 累计变更，末尾统一 `save` 一次；超过条数上限时再补一次（淘汰是物理删除）。
- 图片 `lastUsedAt` 刷新在内存中做，最多每小时落盘一次，避免每次渲染都写 storage。
- 媒体任务在状态变化时落盘；已结束任务按 50 条/会话上限淘汰。

## 版本迁移

- `STORAGE_VERSION = 2` 写入 `storage_version`；具体数据迁移按 key 惰性进行，失败只记日志、不阻断启动。
- 媒体任务：读盘时 `running` → `failed('插件重载中断')`；`done && !notified` 且来源为工具的任务补一次通知；参考图 base64 只存内存，重载后待执行任务失败并提示重新提交。
- 记忆：旧 `memoryMap`/`summaries`/`persona` 由 `memory/v2/migrate.ts` 的 `migrateLegacyMemory` 迁移为新引擎的 MemoryUnit/Observation/心智模型；旧 persona 另由 `MemoryManager.migrateLegacyPersona` 懒迁移（幂等）。
- 挂起队列：旧版内嵌 `session_<sid>` 的 `pendingQueue` 不再读写，改由 `session_<sid>:pending` 分片承载；读不到分片视为空队列。
- 上下文：旧会话首次打开时由 `context/migrate/*` 把 `messages` 惰性迁移为 `evt/rec/ctx_head`（幂等，旧 `messages` 保留到会话下一次保存）；迁移后读写走事件账本，旧 `arc/raw` 分片只读兼容。
- 插件版本升级：`checkUpdate` 对比 `version` 存储键，输出 `src/changelog/<版本>.ts` 的更新日志。
