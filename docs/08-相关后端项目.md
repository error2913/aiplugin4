# 08 - 相关后端项目

仓库根目录 `相关后端项目/` 下存放插件依赖的可选后端服务源码,均可自行搭建后把地址填入"后端"配置分组。除流式输出外,其余服务并非核心功能所必需。

## 流式输出(`流式输出/stream_backend.py`)

- 技术栈:Python + FastAPI + openai SDK + uvicorn;版本号在文件头部 `VERSION = "1.0.2"`。
- 作用:代理 OpenAI 兼容的流式请求,把 SSE 拆分成可增量轮询的结果,供 `streamService.startStream/pollStream/endStream` 使用。
- 接口:`POST /start`(接收 url/api_key/body,返回任务 id)、`GET /poll?id=&after=`(返回 status/results/next_after)、`GET /end?id=`(结束并返回用量)。
- 特性:按标点/换行智能切分输出块、维护符号配对(括号等)、定时清理过期任务(24 小时)、支持工具调用消息。
- 对应配置项:后端 → 流式输出。

## 图片 URL 转 base64(`图片url转base64/urltobase64.py`)

- 技术栈:Python + Flask + requests + Pillow/imageio。
- 作用:下载远程图片并转为 base64,解决部分大模型无法直接访问 QQ 图床图片的问题。
- 特性:失败重试(3 次)、按文件头校验图片格式、GIF 等格式处理。
- 对应配置项:后端 → 图片转base64;行为由"识别图片时将url转换为base64"(永不/自动/总是)控制。

## 用量图表绘制(`用量图表绘制/usage_chart.py`)

- 技术栈:Python + FastAPI + matplotlib。
- 作用:把 token 用量数据绘制为图片,供 `.ai tk y chart` / `.ai tk m chart` 使用。
- 接口:`POST /chart`(chart_type + data),返回图片 URL;临时图片 120 秒过期。
- 对应配置项:后端 → 用量图表。

## 网页 URL 内容读取(`网页url内容读取/puppeteer.js`)

- 技术栈:Node.js + Express + puppeteer。
- 作用:无头浏览器抓取网页,返回标题与正文文本,供 `web_read` 工具使用。
- 接口:`POST /scrape`(body: `{url}`),默认端口 46799。
- 对应配置项:后端 → 网页读取。

## md 和 html 图片渲染(`md和html图片渲染/render.js`)

- 技术栈:Node.js + Express + puppeteer + marked。
- 作用:把 Markdown / HTML 渲染为图片,供 `render_markdown` / `render_html` 工具使用;本地图片资源(`<|img:...|>`)会嵌入渲染。
- 接口:POST 渲染接口,默认端口 37632,请求体上限 10mb。
- 对应配置项:后端 → md和html图片渲染。

## 建议

- 每个后端服务相互独立,可按需部署;仓库内未提供 Dockerfile 与部署编排,推荐按各自说明(requirements.txt / package 依赖)自行部署。
- 除流式输出外,其余服务的公共实例地址已作为默认值写在 `src/config/configs/backend.ts` 中。
