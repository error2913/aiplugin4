# 08 - 相关后端项目

仓库根目录 `backends/` 下存放插件依赖的可选后端服务源码,均可自行搭建后把地址填入"后端"配置分组。除流式输出外,其余服务并非核心功能所必需。

## 一键管理（backends/launcher.py）

启动器仅依赖 Python 标准库,Windows / Linux 通用。默认不启动任何后端;`start` 指定后端时,该后端首次启动才会自动创建独立 venv(`backends/<name>/.venv`)并安装依赖,node 后端首次运行自动 `npm install`。常用命令:

```bash
# 查看后端清单与运行状态
python backends/launcher.py list

# 手动安装/更新依赖(幂等;python 后端装入各自 venv,互不污染)
python backends/launcher.py setup --all

# 启动全部后端(前台,按 Ctrl+C 停止;首次启动自动建 venv 装依赖,异常退出自动拉起)
python backends/launcher.py start --all

# 后台运行(脱离终端;Linux 用 setsid,Windows 用 DETACHED_PROCESS)
python backends/launcher.py start --all --background

# 停止 / 查看状态(支持从其他终端执行,基于 logs/state.json)
python backends/launcher.py stop --all
python backends/launcher.py status

# 启动 Web 管理界面(默认 http://127.0.0.1:8910,仅本机;可启停/装依赖/改端口/看日志,
# 主题跟随系统并可手动切换;打包只在发版时进行,WebUI 不提供打包)
python backends/launcher.py webui

# 查看/修改端口(reset 恢复默认;写入 .runtime.json,重启后端生效;默认值不修改)
python backends/launcher.py port stream-output
python backends/launcher.py port stream-output 3015
python backends/launcher.py port stream-output reset

# 打包后端为 dist/aiplugin4-backends-<版本>.zip
python backends/launcher.py package
```

Linux 若无 `python` 命令,用 `python3` 代替。`start` 为前台监督进程(保持终端打开);也可用 `--background` 后台运行后由 `stop`/`status`/`webui` 管理。每个后端目录下的 `backend.json` 声明了类型/入口/依赖文件/默认端口,`launcher.json` 控制自动拉起策略;端口可通过 `port` 命令或 WebUI 覆盖(存于 `backends/.runtime.json`,已 gitignore,默认值保持不变),后端读取环境变量 `AIPLUGIN4_BACKEND_PORT` 生效。依赖清单(`requirements.txt`/`package.json`)变化后,下次 `start` 会自动重新安装。后端压缩包由发版流程(`release.yml`)自动打包,WebUI 不提供打包入口。

## 流式输出(`backends/stream-output/stream_backend.py`,端口 3010)

- 技术栈:Python + FastAPI + openai SDK + uvicorn;版本号在文件头部 `VERSION = "1.0.2"`。
- 作用:代理 OpenAI 兼容的流式请求,把 SSE 拆分成可增量轮询的结果,供 `streamService.startStream/pollStream/endStream` 使用。
- 接口:`POST /start`(接收 url/api_key/body,返回任务 id)、`GET /poll?id=&after=`(返回 status/results/next_after)、`GET /end?id=`(结束并返回用量)。
- 特性:按标点/换行智能切分输出块、维护符号配对(括号等)、定时清理过期任务(24 小时)、支持工具调用消息。
- 对应配置项:后端 → 流式输出。

## 图片 URL 转 base64(`backends/image-url-to-base64/urltobase64.py`,端口 46678)

- 技术栈:Python + Flask + requests + Pillow/imageio。
- 作用:下载远程图片并转为 base64,解决部分大模型无法直接访问 QQ 图床图片的问题。
- 特性:失败重试(3 次)、按文件头校验图片格式、GIF 等格式处理。
- 对应配置项:后端 → 图片转base64;行为由"识别图片时将url转换为base64"(永不/自动/总是)控制。

## 用量图表绘制(`backends/usage-chart/usage_chart.py`,端口 3009)

- 技术栈:Python + FastAPI + matplotlib。
- 作用:把 token 用量数据绘制为图片,供 `.ai tk y chart` / `.ai tk m chart` 使用。
- 接口:`POST /chart`(chart_type + data),返回图片 URL;临时图片 120 秒过期。
- 对应配置项:后端 → 用量图表。

## 网页 URL 内容读取(`backends/web-read/puppeteer.js`,端口 46799)

- 技术栈:Node.js + Express + puppeteer。
- 作用:无头浏览器抓取网页,返回标题与正文文本,供 `web_read` 工具使用。
- 接口:`POST /scrape`(body: `{url}`)。
- 依赖:首次使用需 `npm install`(启动器 `setup` 命令会自动执行)。
- 对应配置项:后端 → 网页读取。

## md 和 html 图片渲染(`backends/md-html-render/render.js`,端口 37632)

- 技术栈:Node.js + Express + puppeteer + marked。
- 作用:把 Markdown / HTML 渲染为图片,供 `render_markdown` / `render_html` 工具使用;本地图片资源(`<|img:...|>`)会嵌入渲染。
- 接口:POST 渲染接口,请求体上限 10mb。
- 依赖:首次使用需 `npm install`(启动器 `setup` 命令会自动执行)。
- 对应配置项:后端 → md和html图片渲染。

## 发布与打包

- 发版时 `backends/launcher.py package` 会把整个 `backends/`(排除日志/依赖/缓存)打包为 `dist/aiplugin4-backends-<版本>.zip`,随 GitHub Release 发布,解压后即可用 launcher 一键部署。
- 除流式输出外,其余服务的公共实例地址已作为默认值写在 `src/config/configs/backend.ts` 中。
