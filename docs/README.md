# AI 骰娘4 (aiplugin4) 项目知识库

> 面向开发者的项目知识库,基于当前工作区代码整理。
> 面向普通使用者的安装、配置与命令手册请参阅项目根目录的 [README](../README.md)。

## 这是什么

AI 骰娘4 是一个运行在 [SealDice](https://docs.sealdice.com/) 上的 JS 插件,为骰娘接入 OpenAI 兼容的大模型 API,提供智能对话、TRPG 辅助工具、记忆/知识库、图片处理、定时任务等能力。
