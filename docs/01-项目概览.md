# 01 - 项目概览

## 项目定位

AI 骰娘4（`aiplugin4`）是运行在 SealDice 上的 JavaScript 插件，为骰娘接入 OpenAI 兼容格式的大模型 API，让骰娘具备智能对话能力，并深度整合海豹骰子生态的 TRPG 功能（属性检定、牌堆抽取、COC 模组等）。

核心特性：

- **智能对话**：基于 OpenAI 兼容 API，支持上下文感知、角色设定、示例对话、流式输出（通过配套后端中转）。
- **记忆体系**：长期记忆（向量检索 + 标签/用户/群组过滤）、观察记忆、心智模型、配置驱动的知识库（JSON 配置 + Markdown 正文自动分块）。
- **工具系统**：内置 60+ 工具函数（TRPG 检定、牌堆、图片、语音、禁言、消息、定时器等），支持函数调用与提示词工程两种模式；支持外部 MCP 服务器、技能与可配置技能。
- **图片与媒体**：图片识别、表情包制作、Markdown/HTML 渲染为图片、本地图片/语音资源；**语音合成与文生图内置**（在「模型配置」里用 `kind: "tts"` / `"gen"` 声明，异步任务队列 + 完成唤醒，不依赖 tts/tti 依赖插件）。
- **权限体系**：命令权限（会话权限/用户权限/强触权限三维）与工具权限（禁止/默认关闭/按会话开关）。
- **可观测性**：结构化日志（级别控制、密钥脱敏）、token 用量统计与图表、工具调用审计。

## 技术栈

| 类别 | 选型 |
| --- | --- |
| 语言 | TypeScript（源码），打包后为单个 JS 文件 |
| 打包 | esbuild（`tools/build.js`），产物 `dist/aiplugin4.js`，头部拼接 `header.txt` 的 UserScript 注释 |
| 运行时 | SealDice 的 JS 插件沙箱（goja，通过全局 `seal.*` 与扩展实例 `ext` 交互），浏览器平台目标 |
| 模型接入 | OpenAI 兼容 HTTP API（`fetch`），支持对话/图片理解/嵌入三类模型，以及语音合成/文生图媒体用途 |
| 配置解析 | 模型配置为**一个 JSON**（v5，`src/config/v5/`）；角色/技能/MCP/知识库各自为一个 JSON（`src/config/domain/`）；知识库正文按 Markdown 自动分块；媒体用途**默认用内置供应商预设**（`src/model/media_presets.ts`，按 vendor + 模型名给出原生请求结构），需要时用该模型 `request.body` 里的 `{占位符}` + 嵌套表逐键合并覆盖 |
| 模板渲染 | Handlebars（system prompt、记忆、工具提示词等模板） |
| 流式输出 | 通过配套后端服务中转（见 [08-相关后端项目](08-相关后端项目.md)） |
| 冒烟测试 | Node 内置 `seal` 桩加载打包产物 |
| CI | GitHub Actions：可复用质量门禁 `_check.yml`（PR/release 共用）、`docs.yml`（文档站点）、`release.yml`（手动/标签发布） |

## 版本信息

- 版本号唯一来源：`src/config/static_config/meta.ts` 的 `VERSION`（当前 **4.28.0**），作者 `baiyu&错误`，插件名 `aiplugin4`。
- 版本号同步位置：`header.txt`、`package.json`、`package-lock.json`、`src/changelog/<版本>.ts`、`sealpack/info.toml`，由 `npm run version:check` 校验、`npm run version:sync` 回写。
- 更新日志：每个版本一个数据文件 `src/changelog/<版本>.ts`，聚合索引 `src/changelog.ts` 由 `npm run changelog:gen` 生成（勿手改）。
- 开发流程：分支 + squash PR（见 [07-开发指南](07-开发指南.md)）。

## 环境要求

- SealDice v1.4.6+；图片相关功能在分离部署（napcat/llonebot 协议）下建议 v1.5.0+。
- 大模型 API：OpenAI 兼容格式。
- 本地开发：Node.js + npm（构建使用 esbuild，建议较新 Node；CI 使用 Node 20）。

## 顶层目录结构

```text
aiplugin4/
├── src/                  # TypeScript 源码（插件全部逻辑）
│   ├── index.ts          # 插件入口：装配与事件注册
│   ├── pipeline.ts       # 消息/事件唯一分发入口
│   ├── pipeline/         # 去重配对、事件提示词、入站段渲染、端点解析
│   ├── core/             # 宿主端口（storage/clock/fetch）与跨层端口（core/ports）
│   ├── agent/            # 智能体编排、流式、对外 API、子代理框架
│   ├── cmd/              # .ai 命令系统与权限（bootstrap 统一装配）
│   ├── media/            # 媒体生成任务队列（异步提交/结算/唤醒）
│   ├── pub/              # 公开会话目录与只读快照
│   ├── config/           # 配置总线、v5/domain 配置解析、应用钩子、静态常量
│   ├── context/          # 会话上下文、窗口策略、归档、名册、消息渲染
│   ├── memory/           # 记忆门面、知识库、记忆 v2 引擎
│   ├── model/            # 模型注册表、请求管道、媒体模板、列表/余额适配
│   ├── prompt/           # system prompt 分节组装、模板与缓存、记忆数据源端口
│   ├── resource/         # 图片实体/图床/索引与 GC/引用标准/本地资源
│   ├── session/          # 会话状态、触发、收信/发信、持久化
│   ├── tool/             # 工具系统（执行器/注册表/MCP/技能/内置工具）
│   ├── web/              # 联网搜索/抓取 provider 与回退编排
│   ├── judge/ | event/   # 评分触发；事件文本构造与白名单
│   ├── utils/            # 通用工具（消息段、token、revive、并发、时间等）
│   ├── changelog/        # 按版本的更新日志数据文件
│   ├── logger.ts         # 日志模块（级别/标签/脱敏）
│   ├── timer.ts          # 定时器管理
│   ├── usage.ts          # token 用量统计与图表
│   ├── token_calibration.ts # token 估算校准
│   ├── block.ts          # 黑名单
│   └── changelog.ts      # 更新日志聚合索引（生成物）
├── tools/                # 构建脚本（build.js / build-config.js）
├── scripts/              # 测试/验证/打包脚本（harness/ 为共享测试环境）
├── docs/                 # 开发者知识库（本目录）
├── docs-site/            # 文档站点构建与清单校验（mkdocs）
├── ccdocs/               # 第三方参考存档（文档站点 reference/）
├── types/                # seal.d.ts（SealDice API 类型定义）
├── dist/                 # 生产构建产物 aiplugin4.js
├── dev/                  # build-dev 产物（带 sourcemap）
├── sealpack/             # SealRepo 打包源（info.toml / assets/icon.png，scripts/main.js 自动同步）
├── skills/               # 开发用 skills（aiplugin4-test-suite）
├── .github/workflows/    # _check.yml / build-check.yml / docs.yml / release.yml
├── header.txt            # 打包时拼接到产物头部的 UserScript 注释
└── package.json
```

各模块的详细说明见 [03-核心模块详解](03-核心模块详解.md)，分层与依赖规则见 [02-架构设计](02-架构设计.md)。
