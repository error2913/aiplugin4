# 01 - 项目概览

## 项目定位

AI 骰娘4(`aiplugin4`)是运行在 SealDice 上的 JavaScript 插件,为骰娘接入 OpenAI 兼容格式的大模型 API,让骰娘具备智能对话能力,并深度整合海豹骰子生态的 TRPG 功能(属性检定、牌堆抽取、COC 模组等)。

核心特性:

- **智能对话**:基于 OpenAI 兼容 API,支持上下文感知、角色设定、示例对话。
- **记忆体系**:长期记忆(向量检索 + 标签/用户/群组过滤)、短期总结记忆、按角色加载的知识库。
- **工具系统**:内置 40+ 工具函数(TRPG 检定、牌堆、图片、禁言、消息、定时器等),支持函数调用与提示词工程两种模式;支持外部 MCP 服务器与可配置技能。
- **图片处理**:图片识别、表情包制作、Markdown/HTML 渲染为图片、本地图片/语音资源。
- **权限体系**:命令权限(会话权限/用户权限/强触权限三维)与工具权限(禁止/默认关闭/按会话开关)。
- **可观测性**:结构化日志(级别控制、密钥脱敏)、token 用量统计与图表、工具调用审计。

## 技术栈

| 类别 | 选型 |
| --- | --- |
| 语言 | TypeScript(源码),打包后为单个 JS 文件 |
| 打包 | esbuild(`tools/build.js`),产物 `dist/aiplugin4.js`,头部拼接 `header.txt` 的 UserScript 注释 |
| 运行时 | SealDice 的 JS 插件沙箱(通过全局 `seal.*` API 交互,`puerts` 环境),浏览器平台目标 |
| 模型接入 | OpenAI 兼容 HTTP API(`fetch`),支持对话/图片理解/嵌入三类模型 |
| 配置解析 | `js-toml` 解析 TOML 格式的模型与知识库配置 |
| 模板渲染 | Handlebars(system prompt、记忆、知识库、工具提示词等模板) |
| 流式输出 | 通过配套后端服务中转(见 [08-相关后端项目](08-相关后端项目.md)) |
| 冒烟测试 | Node 内置 `seal` 桩(Proxy 兜底)加载打包产物 |
| CI | GitHub Actions(构建检查 + 手动发布 Release) |

## 版本信息

- `src/config/static_config.ts` 中 `VERSION = "4.13.2"`,作者 `baiyu&错误`,插件名 `aiplugin4`。
- 开发遵循「分支 + squash PR」流程(见 [07-开发指南](07-开发指南.md));近期工作围绕:模型配置 TOML 化、Provider 统一请求(超时/重试/用量上报)、智能体编排重构、MCP/技能、日志治理、消息管线、配套后端独立仓库化等。
- README 顶部徽章与 `VERSION` 保持一致（当前 4.13.2）(详见 [09-注意事项与常见问题](09-注意事项与常见问题.md))。

## 环境要求

- SealDice v1.4.6+;图片相关功能在分离部署(napcat/llonebot 协议)下建议 v1.5.0+。
- 大模型 API:OpenAI 兼容格式。
- 本地开发:Node.js + npm(构建使用 esbuild,建议使用较新 Node 版本;`package.json` 中 `engines.node >= 10` 是模板遗留)。

## 顶层目录结构

```text
aiplugin4/
├── src/                  # TypeScript 源码(插件全部逻辑)
│   ├── index.ts          # 插件入口:装配与事件注册
│   ├── pipeline.ts       # 消息管线(非指令/指令/机器人消息)
│   ├── agent/            # 智能体编排(含流式)
│   ├── cmd/              # .ai 命令系统与权限
│   ├── config/           # 配置注册/读取与静态常量
│   ├── context/          # 会话上下文与消息结构
│   ├── memory/           # 记忆/知识库服务
│   ├── model/            # 对话/图片/嵌入模型与请求 Provider
│   ├── prompt/           # system prompt 分节组装
│   ├── resource/         # 图片资源(Image/ImageManager)
│   ├── session/          # 会话/群档案/用户档案
│   ├── tool/             # 工具系统(MCP/技能/内置工具)
│   ├── utils/            # 通用工具函数
│   ├── logger.ts         # 日志模块
│   ├── timer.ts          # 定时器管理
│   ├── update.ts         # 版本更新日志
│   ├── usage.ts          # token 用量统计与图表
│   └── trigger.ts        # 触发模块(预留)
├── tools/                # 构建脚本(build.js / build-config.js)
├── scripts/              # smoke.js 冒烟、prepare-sealpack.js / build-release.js 打包、deps.cjs 依赖清单、release-notes.js 发布正文
├── types/                # seal.d.ts(SealDice API 类型定义)
├── dist/                 # 构建产物 aiplugin4.js
├── dev/                  # build-dev 产物(带 sourcemap)
├── build/                # 陈旧的 tsc 输出(与构建流程无关,见注意事项)
├── sealpack/             # SealRepo 打包源(info.toml / assets/icon.png,scripts/main.js 自动同步)
├── skills/               # 开发用 skills(aiplugin4-test-suite)
├── .github/workflows/    # build-check.yml / release.yml
├── header.txt            # 打包时拼接到产物头部的 UserScript 注释
└── package.json
```

各模块的详细说明见 [03-核心模块详解](03-核心模块详解.md)。
