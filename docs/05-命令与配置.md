# 05 - 命令与配置

> 本章命令语法均来自 `src/cmd/sub_cmd/` 当前源码;README 命令手册会随发版同步,如与 README 不一致以本章为准。

## `.ai` 命令体系

根命令 `.ai`(`AI` 大写同样注册),子命令别名经 `ALIAS_MAP` 归一(常用:`priv→privilege`、`ses→session`、`st→set`、`ck→check`、`clr→clear`、`sb→standby`、`fgt→forget`、`memo→memory`、`p→private`、`g→group`、`tk→token`、`y→year`、`m→month`、`lcl→local`、`ran→random`、`lst→list`、`rm→remove`)。支持 `--page=<数字>`(别名 `--p`)翻页;`.ai help <一级子指令>` 或 `.ai <一级子指令> help` 可查看对应子命令帮助(后者带更多参数时交由子命令自身处理,如 `.ai tool help <函数名>`)。

### 子命令一览(源码为准)

| 子命令 | 说明 | 主要用法 |
| --- | --- | --- |
| `privilege` | 权限管理(骰主) | `.ai priv ses st <ID> <会话权限>` 设置会话权限;`.ai priv ses ck <ID>` 检查会话权限;`.ai priv st <指令> <权限限制>` 修改指令权限;`.ai priv show <指令>`;`.ai priv reset` |
| `prompt` | 查看 system prompt(骰主) | `.ai prompt` |
| `status` | 查看当前会话 AI 状态 | `.ai status` |
| `live` | 查看会话实时运行状态 | `.ai live` 查看当前会话(流式/运行/排队/定时器);`.ai live all` 全局活跃会话总览(骰主) |
| `ctxn` | 上下文名字相关 | `.ai ctxn status`;`.ai ctxn set [nick/card]`;`.ai ctxn mod <0|1|2>`(0 不自动改,1 昵称,2 群名片) |
| `timer` | 定时器管理 | `.ai timer lst`;`.ai timer clr`(需邀请者以上) |
| `on` | 开启 AI 及各触发模式(需会话权限 1) | `.ai on` 开启非指令正则触发;`--r`、`--j`、`--c=<条>`、`--t=<秒>`、`--p=<%>`、`--a=<开始-结束-次数>` 单独开启对应模式;可组合,如 `.ai on --t --p=42` |
| `standby` | 开启待机模式(仅记录不主动发言) | `.ai standby`(需邀请者以上) |
| `off` | 关闭 AI(含非指令正则触发) | `.ai off` 全部关闭;`--r/--j/--c/--t/--p/--a` 单独关闭某模式(需邀请者以上) |
| `forget` | 遗忘上下文 | `.ai fgt` 全部;`.ai fgt assistant` 清除 assistant+tool;`.ai fgt user` 清除 user |
| `role` | 切换角色设定 | `.ai role` 查看;`.ai role <名称>` 切换(需邀请者以上) |
| `image` | 图片管理 | `.ai img list [lcl]`;`.ai img itt [图片] <提示词>`;`.ai img find <图片ID>` |
| `memory` | 记忆管理 | 见下文 |
| `tool` | 工具管理 | 见下文 |
| `ignore` | 群内忽略名单 | `.ai ign add <用户ID>`;`.ai ign rm <用户ID>`;`.ai ign lst`(仅群聊) |
| `block` | 黑名单管理(骰主) | `.ai block add <用户ID/群ID> <原因>`;`.ai block rm <用户ID/群ID>`;`.ai block list`;被拉黑对象无法触发 AI 对话,指令不受影响;AI 建议拉黑默认需骰主确认,可在工具配置关闭 |
| `token` | token 用量统计 | 见下文 |
| `stop` | 完全暂停当前对话（打断流式/工具链/排队，清计时器） | `.ai stop` |
| `model` | 查看/设置全局分用途模型(骰主) | `.ai model` 查看全部用途;`.ai model <用途>` 查看指定用途;`.ai model <用途> <模型标识>` 设置(标识形如 `text[0]:deepseek-chat`);旧写法 `.ai model <模型名>` 等价于设置 chat 用途 |
| `sample` | 示例智能体(未注册到根命令) | 仅开发参考 |

### memory 子命令

```text
.ai memo status                    # 记忆状态
.ai memo add <内容>                # 添加长期记忆
.ai memo list [页码]               # 展示长期记忆(支持 --page)
.ai memo update <ID> <新内容>      # 更新长期记忆
.ai memo delete <ID1> <ID2> --关键词  # 删除长期记忆(支持关键词过滤,物理删除不可恢复)
.ai memo clear                    # 清除长期记忆(物理删除不可恢复)
.ai memo obs on/off               # 开启/关闭观察记忆(会话级)
.ai memo obs list                 # 展示观察记忆(支持 --page)
.ai memo obs view <ID>            # 观察记忆详情
.ai memo obs clr                  # 清除观察记忆
.ai memo obs                      # 立即生成一次观察记忆(仅当前会话,不带 --u/--g)
.ai memo consolidate              # 立即巩固一次记忆(合并重复观察、清理过期观察)
.ai memo reflect <问题>           # 基于记忆推理
.ai memo mm list [页码]           # 心智模型列表(支持 --page)
.ai memo mm view <ID>             # 心智模型详情
.ai memo mm add <问题> [答案]     # 添加/更新心智模型(不填答案时基于记忆重新生成并保留旧答案兜底;--tag=xx 范围标签;--mode=full|delta 刷新方式,缺省跟随配置且更新时保留原配置;--auto/--no-auto 显式开关自动刷新)
.ai memo mm refresh [ID]          # 刷新心智模型(基于当前记忆重新推理)
.ai memo mm del <ID|问题关键词>    # 删除心智模型(ID 或问题名/关键词,关键词唯一命中时直接删除)
```

范围:默认当前会话(私聊=个人,群聊=当前群);`--u` 查看/操作本人个人记忆,`--g` 当前群;`--u=<ID>`/`--g=<ID>` 查看他人/其他群(仅骰主);`--u` 与 `--g` 不能同用;裸 `obs` 不带范围参数(仅当前会话)。权限:memo 子命令普通用户可用(`U`),`obs on/off` 需会话权限 1(`S`)。

### tool 子命令

```text
.ai tool                            # 列出所有工具及开关状态
.ai tool help <函数名>               # 查看工具详情与参数
.ai tool on|off [<函数名>]          # 开关全部或指定工具(on/off 需邀请者以上)

```

### token 子命令

```text
.ai tk lst                          # 有使用记录的模型
.ai tk sum                          # 所有模型用量总和
.ai tk all                          # 各模型用量明细
.ai tk [y/m] (chart)                # 最近 12 个月 / 31 天用量,chart 生成图片
.ai tk <模型名> [y/m] (chart)       # 指定模型用量
.ai tk clr [<模型名>]               # 清除用量记录
```

## 权限体系

### 用户权限等级(PRIVILEGE_LEVEL_MAP)

| 等级 | 数值 | 说明 |
| --- | ---: | --- |
| blacklist | -30 | 黑名单用户 |
| user | 0 | 普通用户 |
| inviter | 40 | 邀请者 |
| admin | 50 | 群管理员 |
| owner | 60 | 群主 |
| whitelist | 70 | 白名单用户 |
| master | 100 | 骰主 |

### 命令权限(CmdPrivInfo)

每个命令/子命令有一个三元组 `[会话所需权限, 会话检查通过后用户所需权限, 强触所需权限]`:

- 用户权限来自 `ctx.privilegeLevel`(SealDice),会话权限来自 `session.setting.priv`。
- 通过规则:会话权限 ≥ 第 1 项 **且** 用户权限 ≥ 第 2 项;或用户权限 ≥ 第 3 项(强触)。
- 支持 `*` 通配与多级嵌套(子命令可再挂子命令)。
- 预置常量:`U = [0,0,0]`、`M = [0,100,100]`、`I = [0,40,40]`、`S = [1,40,100]`。
- 自定义权限持久化在 `cmdPriv` 存储键,`.ai priv reset` 可恢复默认;`priv` 命令本身不可被修改权限。

### 模型配置 TOML 示例

```toml
# 纯文本模型
name = "deepseek-chat"
api_key = "sk-xxxx"
use = ["chat"]
provider = "deepseek"   # 可省略,按名称自动识别

# 覆盖请求参数(可选)
[body]
temperature = 0.8
max_tokens = 2048
```

纯文本模型 `use` 可填 `chat`(普通对话)/`compression`(消息压缩)/`summarization`(记忆总结)/`judge`(评分插话判断);多模态模型 `use` 可填 `image-understanding`(识图)或 `chat`/`compression`/`summarization`/`judge` 等对话用途(作多模态对话模型),嵌入模型 `use = ["text-embedding"]`;嵌入输出维度在嵌入模型的 `[body] dimensions` 配置(默认 1024),配置嵌入模型后长期记忆与知识库启用语义检索,未配置时自动降级为关键词检索(知识库加载本身不请求嵌入)。
