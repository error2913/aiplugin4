# 05 - 命令与配置

> 本章命令语法均来自 `src/cmd/sub_cmd/` 当前源码,而非 README(README 的命令手册已过时)。

## `.ai` 命令体系

根命令 `.ai`(`AI` 大写同样注册),子命令别名经 `ALIAS_MAP` 归一(常用:`priv→privilege`、`ses→session`、`st→set`、`ck→check`、`clr→clear`、`sb→standby`、`fgt→forget`、`memo→memory`、`p→private`、`g→group`、`tk→token`、`y→year`、`m→month`、`lcl→local`、`stl→steal`、`ran→random`、`lst→list`、`rm→remove`)。支持 `--page=<数字>`(别名 `--p`)翻页。

### 子命令一览(源码为准)

| 子命令 | 说明 | 主要用法 |
| --- | --- | --- |
| `privilege` | 权限管理(骰主) | `.ai priv ses st <ID> <会话权限>` 设置会话权限;`.ai priv ses ck <ID>` 检查会话权限;`.ai priv st <指令> <权限限制>` 修改指令权限;`.ai priv show <指令>`;`.ai priv reset` |
| `prompt` | 查看 system prompt(骰主) | `.ai prompt` |
| `status` | 查看当前会话 AI 状态 | `.ai status` |
| `ctxn` | 上下文名字相关 | `.ai ctxn status`;`.ai ctxn set [nick/card]`;`.ai ctxn mod <0|1|2>`(0 不自动改,1 昵称,2 群名片) |
| `timer` | 定时器管理 | `.ai timer lst`;`.ai timer clr`(需邀请者以上) |
| `on` | 开启 AI 及各触发模式(需会话权限 1) | `.ai on` 开启非指令正则触发;`--r`、`--c=<条>`、`--t=<秒>`、`--p=<%>`、`--a=<开始-结束-次数>` 单独开启对应模式;可组合,如 `.ai on --t --p=42` |
| `standby` | 开启待机模式(仅记录不主动发言) | `.ai standby`(需邀请者以上) |
| `off` | 关闭 AI(含非指令正则触发) | `.ai off` 全部关闭;`--r/--c/--t/--p/--a` 单独关闭某模式(需邀请者以上) |
| `forget` | 遗忘上下文 | `.ai fgt` 全部;`.ai fgt assistant` 清除 assistant+tool;`.ai fgt user` 清除 user |
| `role` | 切换角色设定 | `.ai role` 查看;`.ai role <名称>` 切换(需邀请者以上) |
| `image` | 图片管理 | `.ai img list [stl/lcl]`;`.ai img stl [on/off/f]`;`.ai img itt [图片] <提示词>`;`.ai img find <图片ID>` |
| `memory` | 记忆管理 | 见下文 |
| `tool` | 工具管理 | 见下文 |
| `ignore` | 群内忽略名单 | `.ai ign add @xxx`;`.ai ign rm @xxx`;`.ai ign lst`(仅群聊) |
| `block` | 黑名单管理(骰主) | `.ai block add <统一ID/@xxx> <原因>`;`.ai block rm <统一ID/@xxx>`;`.ai block list`;被拉黑对象无法触发 AI 对话,指令不受影响;AI 建议拉黑默认需骰主确认,可在工具配置关闭 |
| `token` | token 用量统计 | 见下文 |
| `shut` | 打断当前流式对话 | `.ai shut` |
| `model` | 查看/设置会话模型 | `.ai model`;`.ai model <模型名>`;`.ai model clr` |
| `sample` | 示例智能体(未注册到根命令) | 仅开发参考 |

### memory 子命令

```text
.ai memo status (@xxx)              # 记忆状态,@ 查看个人记忆状态
.ai memo [p/g] st <内容>             # 设置个人/群聊设定(个人≤20字,群聊≤30字)
.ai memo [p/g] st clr               # 清除设定
.ai memo [p/g] del <ID1> <ID2> --关键词1 --关键词2   # 删除记忆
.ai memo [p/g/short] list           # 展示记忆/短期记忆(支持 --page)
.ai memo [p/g/short] clr            # 清除记忆/短期记忆
.ai memo short [on/off]             # 开启/关闭短期记忆
.ai memo sum                        # 立即总结一次短期记忆
.ai memo sum clr                    # 清除总结记忆
```

权限:private 分支普通用户可用;group 分支需邀请者以上(`I`);short 分支需会话权限 1(`S`)。

### tool 子命令

```text
.ai tool                            # 列出所有工具及开关状态
.ai tool help <函数名>               # 查看工具详情与参数
.ai tool on|off [<函数名>]          # 开关全部或指定工具(on/off 需邀请者以上)
.ai tool call <函数名> --参数=值     # 试用工具(call 需骰主),参数可尝试 JSON 解析
```

### token 子命令

```text
.ai tk lst                          # 有使用记录的模型
.ai tk sum                          # 所有模型用量总和
.ai tk all                          # 各模型用量明细
.ai tk [y/m] (chart)                # 最近 12 个月 / 31 天用量,chart 生成图片
.ai tk <模型名> [y/m] (chart)       # 指定模型用量
.ai tk clr [<模型名>]               # 清除用量记录
```

## 权限体系

### 用户权限等级(PRIVILEGE_LEVEL_MAP)

| 等级 | 数值 | 说明 |
| --- | ---: | --- |
| blacklist | -30 | 黑名单用户 |
| user | 0 | 普通用户 |
| inviter | 40 | 邀请者 |
| admin | 50 | 群管理员 |
| owner | 60 | 群主 |
| whitelist | 70 | 白名单用户 |
| master | 100 | 骰主 |

### 命令权限(CmdPrivInfo)

每个命令/子命令有一个三元组 `[会话所需权限, 会话检查通过后用户所需权限, 强触所需权限]`:

- 用户权限来自 `ctx.privilegeLevel`(SealDice),会话权限来自 `session.setting.priv`。
- 通过规则:会话权限 ≥ 第 1 项 **且** 用户权限 ≥ 第 2 项;或用户权限 ≥ 第 3 项(强触)。
- 支持 `*` 通配与多级嵌套(子命令可再挂子命令)。
- 预置常量:`U = [0,0,0]`、`M = [0,100,100]`、`I = [0,40,40]`、`S = [1,40,100]`。
- 自定义权限持久化在 `cmdPriv` 存储键,`.ai priv reset` 可恢复默认;`priv` 命令本身不可被修改权限。

## 配置分组总览

配置在 SealDice WebUI 的插件设置中按分组展示,键名与 `configs/*.ts` 注册时一致。完整键清单见 [03-核心模块详解](03-核心模块详解.md) 的表格;这里补充几个常用配置的实际键名:

| 分组 | 常用键名 | 说明 |
| --- | --- | --- |
| 基础 | 日志级别、请求超时时限、是否开启全局待机 | 全局开关 |
| 模型 | 对话模型/图片模型/嵌入模型 | TOML 每行一个;`name`/`api_key`/`use` 必填,`use` 可选项:`chat`/`compression`/`summarization`(对话)、`image-understanding`(图片)、`text-embedding`(嵌入);`provider`/`base_url` 可自动识别;默认对话模型取列表第一项;可加 `[body]` 覆盖请求参数 |
| 对话 | 角色设定名称、角色扮演设定、示例对话、对话保存轮数、上下文最大token、消息压缩阈值 | 角色一对一对齐,`$gSYSPROMPT` 选择 |
| 消息接收 | 接收图片/指令消息/骰子发送的消息、忽略消息豹语条件、忽略消息正则表达式 | |
| 消息触发 | 触发正则表达式、触发需要满足的条件、触发次数上限、触发次数补充间隔、默认向量相似度 | 令牌桶配额 |
| 工具 | 开启调用函数功能、切换为提示词工程、允许连续调用函数次数、工具响应压缩触发字数、禁止/默认关闭的函数、MCP服务器配置、技能配置、ai语音使用的音色 | |
| 记忆 | 启用长期/总结/知识库记忆、向量维度、长期记忆上限/展示数量、知识库记忆(TOML) | |
| 回复 | 回复引用、回复最大字数、分段发送延时/基础延时/含图额外延时、禁止回复复读、回复消息过滤正则表达式 | |
| 后端 | 流式输出、图片转base64、联网搜索、网页读取、用量图表、md和html图片渲染 | 可自建,见 [08-相关后端项目](08-相关后端项目.md) |
| 资源 | 本地图片路径、本地语音路径(支持 `语音名=路径`) | 供 system prompt 列出可发送资源 |

### 模型配置 TOML 示例

```toml
# 对话模型
name = "deepseek-chat"
api_key = "sk-xxxx"
use = ["chat"]
provider = "deepseek"   # 可省略,按名称自动识别

# 覆盖请求参数(可选)
[body]
temperature = 0.8
max_tokens = 2048
```

对话模型 `use` 可填 `chat`(普通对话)/`compression`(消息压缩)/`summarization`(记忆总结);图片模型 `use = ["image-understanding"]`,嵌入模型 `use = ["text-embedding"]`,且嵌入输出维度需与 `向量维度` 配置一致。
