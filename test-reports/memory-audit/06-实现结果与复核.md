## 1. 实现结果（行为）

已打通的目标链路：

```
AI run 结束（finally，acquired && !headless && subagentDepth===0）
  → MemoryScheduler.onRunEnd
       collectContextBacklog（只读事件账本 → mem_cursor.pending，0 LLM）
       无待抽取/无 AI 活动 → 不入队、不调 LLM
       pending 达水位 → enqueue extract（job 只存 sessionId/throughSeq/textLength）
  → 后台 tick（持久 mem_sched_v1，单并发）
       extract: MemoryService.extractFromChunk → facts 路由到 user/group/global bank
                commit pending（失败不 commit，退避重试）
       consolidate: pending facts → 观察（evidence/proofCount/history）
       mm_refresh: watermark/interval/失败冷却门控 → full/delta
  → 下一轮 MemoryService.buildMemoryPrompt
       当前 bank + 群内最近发言者个人 bank + global
       单渲染器预算/去重；owner/origin/public 可见性过滤
  → 命令/工具/手动 mm refresh 同步路径（唯一等待 LLM 的路径）
```

关键行为：

- **三层 bank**：`user_<sid>` / `group_<gid>` / `global_<agent>`；`global_*` 的 `*` 归一为 `main`，并兼容旧 `global__` 孤儿改名。
- **原始事实 append-only**：无同实体合并；完全相同文本去重；`createdAtSeq` 单调；纠错走 `invalidated + supersedes`。
- **观察**：独立表；evidence/proofCount=distinct live sources；history（created/reinforced/refined/contradicted/merged）；过期仅派生（不再物理删除）。
- **心智模型**：`sourceQuery/content/structuredContent/trigger/tags/maxTokens/watermark/reflectResponse/history`；full/delta；未命中 block 逐字节保留；空输出保留旧内容；失败 30min 冷却；delta 48h full 重建；模板版本化播种，删除后不自动复活。
- **reflect**：新鲜模型快路径（0 合成 LLM）→ 观察/事实；strict 不回退 dump；返回 basedOn。
- **调度**：持久队列；无 AI 不跑自动任务；AI 后 30min 宽限；主 AI 轮内自动任务让路；在线探测 `requestLimiter` 不排队；每小时预算/单并发/连续失败熔断；重载清 running；模板 seed 由调度器执行。
- **隐私**：DM 事实默认 `vis:owner`；群来源个人事实默认 `vis:origin:<gid>`；群 bank `public`；global `public`；旧 user bank 事实/观察迁移统一收紧 `owner`；群聊 private 默认不写个人；global 自动抽取默认关；保留前缀不可由 LLM 伪造。
- **上下文解耦**：`src/context/**` 无 memory import、无 `.memory.`；archiver 3 处记忆调用删除；roster 兜底删除；静态守卫单测。
- **命令/工具/配置**：`.ai memo` 范围 `--u/--g/--self`，`clear/obs clr` 必须 `--yes`；`#N` ID；工具 12→7；配置按 05 默认表落地并被消费；v2→v3 惰性迁移 + 迁移前备份。
